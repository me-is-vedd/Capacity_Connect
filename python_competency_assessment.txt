Q1. Which of the following is the correct syntax for creating a list in Python?

A. {1, 2, 3}
B. [1, 2, 3]
C. (1, 2, 3)
D. <1, 2, 3>

Correct Answer: B
Difficulty: Easy


Q2. What will be the output of the following code?

x = 10
y = 3
print(x // y)

A. 3.33
B. 3
C. 4
D. 1

Correct Answer: B
Difficulty: Easy


Q3. Which keyword is used to define a function in Python?

A. function
B. define
C. def
D. func

Correct Answer: C
Difficulty: Easy


Q4. What will be the output of the following code?

A. 1
B. 2
C. 3
D. 4

Correct Answer: C
Difficulty: Medium


Q5. What will be the output of the following code?

Difficulty: Medium

0–1 correct = Level 1 (Beginner)
2–3 correct = Level 2 (Basic)
4 correct = Level 3 (Intermediate)
5 correct = Level 4 (Advanced)
