CapacityConnect — UI/UX Design Prompt
Design a modern, premium, enterprise-grade web application called CapacityConnect, an AI-powered
organizational capacity-building and learning management platform.

Product Concept
CapacityConnect is NOT a traditional LMS. Its core purpose is to identify what employees need to learn
by comparing their current competencies with the competencies required for their role, calculating
skill gaps, recommending personalized learning, tracking assessments, measuring competency
improvement, and providing organization-wide capacity analytics.
The central product loop is:
Assess → Identify → Recommend → Learn → Evaluate → Improve → Analyze
The UI should make this competency-driven workflow immediately understandable.

Use a sophisticated navy / indigo / blue primary palette, supported by neutral white/gray surfaces.

20. UX Principles
The most important UX principle is:
Every learning recommendation should connect back to a competency gap.

13

Users should always understand:
What do I need to improve? ↓ Why do I need to improve it? ↓ What should I learn? ↓ What
happens after I complete it?
Avoid making the product feel like a generic course marketplace.
The dashboard should prioritize competency intelligence first, courses second.

21. Responsive Design
Design for:
• Desktop
• Tablet
• Mobile
Desktop: Persistent sidebar + spacious dashboard.
Tablet: Collapsible sidebar.
Mobile: Bottom navigation or compact hamburger navigation.
Cards should stack naturally.
Tables should become scrollable or transform into mobile cards.

22. Hackathon Demo Optimization
Optimize the UI around two demo journeys.

Employee Demo
Login → Employee Dashboard → Competency Profile → Take Assessment → Show Skill Gap → AI/RuleBased Recommendation → Open Course → Take Quiz → Show Improved Competency

Administrator Demo
Admin Dashboard → Organization Skill Gaps → Identify Critical Competency → View Affected
Departments → Create/Recommend Training Program → Knowledge Hub
The UI should make these journeys visually obvious and require minimal navigation.

23. Important Product Messaging
Use the following positioning prominently in appropriate places:
CapacityConnect Competency-driven organizational learning

24. Final Design Goal
The finished UI should look like a real enterprise SaaS product ready for a hackathon demo, not a
generic dashboard template.
Prioritize: 1. Competency intelligence 2. Skill-gap visualization 3. Personalized recommendations 4.
Learning progress 5. Assessment → competency improvement 6. Organizational analytics 7. Knowledge
sharing
Make the interface feel intelligent, trustworthy, modern, data-driven, and highly polished, while
remaining simple enough that a first-time user immediately understands what to do next.
